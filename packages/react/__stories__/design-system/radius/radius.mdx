Use `corner-radius-*`. **100** is 4px; each step adds 4px. `full` is a pill.

## How to use

<Source
  dark
  code={`
<div class="corner-radius-400">card</div>
<button class="corner-radius-full">button</button>
`}
  language="html"
/>

One side only: `corner-radius-t-300`, `corner-radius-b-*`, `l`, `r`. In custom CSS, `border-radius: var(--corner-radius-300)`.
