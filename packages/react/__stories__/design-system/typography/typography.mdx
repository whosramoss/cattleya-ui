Use `title-*`, `body-*`, and `label-*`. Geist is the only family. Default weights: title **600**, body and label **500**. Suffixes: `-semi-strong` is 600, `-strong` and body `-highlight` are 700.

The default page stack is the same as Use Cases: page title, section title, supporting copy, then labels.

## Scale

There is no `title-500`. Prefer the classes above — do not compose raw `font-size-*` / `line-height-*`.

## How to use

Same recipe as the preview. Pair type with `text-primary` / `text-secondary` — color tokens live in Colors.

<Source
  dark
  code={`
<h1 class="title-400 text-primary">page title</h1>
<h2 class="title-200 text-primary">section title</h2>
<p class="body-150 text-secondary">supporting text</p>
<p class="label-150-strong text-primary">emphasized label</p>
<p class="label-150 text-secondary">helper label</p>
`}
  language="html"
/>

Bold a word inside body with `body-100-highlight` / `body-150-highlight`. Do not use `label-*` as paragraph text.
