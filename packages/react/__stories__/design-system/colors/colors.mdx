Design tokens are reusable attributes that replace hardcoded design values such as colors, spacing, typography, and shadows, ensuring consistency and flexibility across the system. They let components be defined by meaning (semantics) instead of appearance, which makes global visual identity changes easier.

The structure is organized in three levels: **core tokens**, which store raw values; **semantic tokens**, which assign meaning and usage context to those values; and **component tokens**, which apply semantic tokens to specific interface components.
