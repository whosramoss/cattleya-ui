Columns, gutter, and page margin are one layout. Distances come from the spacing scale: `--spacing: 0.4rem` (4px).

The class number is the step, not the pixel value — `gap-4` is **16px**, `var(--spacing-8)` is **32px**.

## Grid Scale

Gutter and margin are spacing utilities. Tailwind prefixes follow this file (`--breakpoint-sm` 600px, `--breakpoint-md` 900px, `--breakpoint-lg` 1200px) — not the names Small / Medium / Large.

## Spacing scale

The number on the class is the step, not the pixel size. One step is **4px (0.4rem)**. `gap` is the space between children, `p` is padding, `m` is margin — same step, same size.

- **spacing-1** — 4px (0.4rem). `gap-1`, `p-1`, `m-1`
- **spacing-2** — 8px (0.8rem). `gap-2`, `p-2`, `m-2`
- **spacing-3** — 12px (1.2rem). `gap-3`, `p-3`, `m-3`

The rest of the scale is the same math: step × 4px. Rows tagged in the preview are the values the grid already uses.

## How to use

Inside a column, keep using the same scale for padding and stack gap — `p-4` (16px), `gap-3` (12px), `gap-8` (32px).

Custom CSS uses the same step numbers:

<Source
  dark
  code={`
.component {
  padding: var(--spacing-4); /* 16px */
  gap: var(--spacing-6);     /* 24px */
  margin-inline: var(--spacing-8); /* 32px */
}
`}
  language="css"
/>

Avoid raw pixels and treating the token number as pixels:

<Source
  dark
  code={`
.component {
  gap: var(--spacing-8); /* 32px, not 8px */
  padding: 8px;          /* outside the scale */
}
`}
  language="css"
/>
